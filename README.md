# 聊天文字调色 Chat Text Painter

SillyTavern UI 扩展：**仅作用于酒馆聊天消息正文**，对三类文本分别调色，互不干扰。

## 功能

| 文本类别 | 覆盖范围 |
| --- | --- |
| 主要文本 | 消息正文（不含斜体 / 引用） |
| 斜体文本 | `*斜体*`（`em` / `i`） |
| 引用文本 | `> 引用`（`blockquote` / `q`）＋成对中英文双引号对话（“...” / "..."） |

每类文本三种模式：

- **跟随酒馆**：不覆盖，完全交给主题
- **纯色**：自定义颜色（CSS 覆盖，不拆 DOM）
- **渐变**：自定义起止色 + 角度（0–360°，与 CSS 渐变角度一致：90° 自左向右）
  - **光晕**：开关 + 强度 0–100。开启后逐字按角度取色，每个字符挂跟随字色的
    三层霓虹光晕（近层亮边 + 中层柔晕 + 外层扩散），蓝段发蓝光、黄段发黄光；
    接近垂直的角度（0°/180°±22.5°）取渐变中间色整段着色
  - 光晕关闭时使用纯 CSS 渐变裁切，最平滑、最轻量

## 性能

- 纯色模式零 DOM 开销；渐变模式仅处理消息正文文本节点
- 光晕通过 IntersectionObserver 离屏门控：消息离开视口边（600px 余量）自动
  关闭逐字光晕，滚回自动恢复，屏内观感不降级
- 流式生成期间 rAF 调度 + 40ms 节流实时重绘，不等待生成结束
- 长聊天全量重绘按每帧 12ms 时间预算分批执行，不卡滚动

## 安装

方式一（推荐）：酒馆 → 扩展 → Install extension，填入本仓库地址
（仓库 / 目录名必须为 `st-chat-text-painter`）。

方式二：把本目录整体复制到酒馆的 `data/<user>/extensions/st-chat-text-painter/`，
重启或刷新页面。

## 使用

扩展设置面板 → 「聊天文字调色」：三类文本各自独立设置；改动实时生效；
「重绘当前聊天」可手动刷新。每张卡片底部有与正文同规则的实时预览，
可直接在预览上调颜色 / 角度 / 光晕强度。

## 兼容性

- 适配 SillyTavern 1.19.x（ST1.19.0 实测目标）
- 与 Glimmer / Moonlit Echoes 主题共存；颜色与光晕经高特异性
  `!important` + CSS 变量兜底，可抵御主题自带文字阴影与文字填充色
- 请勿与同类改色扩展（如 st-colorful-text）同时启用
